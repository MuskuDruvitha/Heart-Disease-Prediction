

# Heart Disease Prediction using Machine Learning

## Project Overview

This project predicts whether a person is likely to have heart disease based on medical attributes.
Machine Learning classification algorithms are used to train models and compare their performance.

## Models Used

*Logistic Regression
*Support Vector Machine (SVM)

Both models were trained on the heart disease dataset and evaluated using accuracy score.

## Accuracy Comparison:

The Logistic Regression model achieved approximately 85% training accuracy and 80% testing accuracy.

The Support Vector Machine (SVM) model achieved approximately 86% training accuracy and 82% testing accuracy.

Overall, the SVM model performed slightly better than Logistic Regression on the testing data.
